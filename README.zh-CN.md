# 毛泽东名言海报 Skill

一个可复用的 Agent Skill：用户只输入一条毛泽东名言，自动生成 **一张 9:16 竖版红色纪念风格海报**。

## 使用方式

Skill 安装并启用后，用户只需输入：

```text
星星之火，可以燎原。
```

Agent 自动生成一张图片，不再询问风格、颜色、比例或版式。

## 默认视觉规范

- 深红色、朱红色背景，旗帜/布幔褶皱质感。
- 中央纵向暖色光区，复古胶片颗粒。
- 暖黄色/象牙白中文大字，柔和发光。
- 名言为主体，自动进行均衡换行。
- 下方偏右添加“毛泽东”署名。
- 下半部分可融入低对比度暗红人物剪影。
- 默认不添加纪念年份、活动文案、Logo、二维码或水印。

## 关键设计

采用“AI 生成背景 + 本地精确排版”的优先方案：

1. 图片模型只生成无文字的红色背景。
2. `render_poster.py` 使用本机中文字体，将用户提供的名言准确叠加到背景上。
3. 检查最终图片，只交付一张。

这样可以降低图片模型直接绘制中文时出现错字、漏字的概率。

## 兼容平台

提供统一 Skill 源文件，可安装到：

- `.agents/skills/`
- `.codex/skills/`
- `.claude/skills/`
- `.pi/skills/`
- `.opencode/skills/`

安装命令：

```bash
python3 scripts/install_skill.py \
  --project /你的项目路径 \
  --targets agents,codex,claude,pi,opencode
```

如需覆盖已有版本，增加 `--force`。

## 运行要求

- Agent 环境必须提供实际的图片生成能力。
- 精确排版路径需要 Python 3、Pillow 和本机中文字体。
- 如果没有图片生成工具，Skill 必须明确说明，不能只返回提示词并声称已生成图片。
